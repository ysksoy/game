# Amazonギフトコード暗号化機能の使い方

このドキュメントでは、ゲームクリア時にAmazonギフトコードを表示する機能の設定方法を説明します。

## 概要

この機能は、ゲームクリア時に「合言葉」を入力させ、正しい合言葉が入力された場合にのみAmazonギフトコードを表示します。ギフトコードはソースコード内にAES暗号化された状態で保存されるため、直接読み取られることはありません。

## セットアップ手順

### ステップ1：暗号化文字列の生成

1. `scripts/encrypt-gift-code.js` ファイルを開きます

2. 以下の2つの値を設定します：
   ```javascript
   const GIFT_CODE = 'XXXX-XXXXXX-XXXX';  // ← 実際のAmazonギフトコードに置き換えてください
   const PASSPHRASE = 'あけましておめでとう';  // ← 合言葉を設定してください
   ```

3. スクリプトを実行します：
   ```bash
   node scripts/encrypt-gift-code.js
   ```

4. 出力された暗号化文字列（`U2FsdGVkX1+...` のような形式）をコピーします

### ステップ2：暗号化文字列をゲームに組み込む

1. `src/components/game/Level.tsx` ファイルを開きます

2. ファイルの先頭付近にある `ENCRYPTED_GIFT_CODE` 定数を探します：
   ```typescript
   const ENCRYPTED_GIFT_CODE = "U2FsdGVkX1+XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX"; // ← ここを置き換えてください
   ```

3. ステップ1でコピーした暗号化文字列を貼り付けます：
   ```typescript
   const ENCRYPTED_GIFT_CODE = "U2FsdGVkX1+abc123def456..."; // ← 実際の暗号化文字列
   ```

4. ファイルを保存します

### ステップ3：動作確認

1. ゲームを起動します：
   ```bash
   npm run dev
   ```

2. ゲームをクリアします

3. 「合言葉を入力してください」というプロンプトが表示されます

4. ステップ1で設定した合言葉を入力します

5. 正しい合言葉を入力すると、Amazonギフトコードが表示されます

## 仕組み

### 暗号化
- `crypto-js` ライブラリのAES暗号化を使用
- ギフトコードは合言葉（パスフレーズ）で暗号化されます
- 暗号化された文字列はBase64エンコードされた形式で保存されます

### 復号
- ゲームクリア時に `window.prompt` で合言葉を入力させます
- 入力された合言葉を使ってAES復号を試みます
- 復号に成功し、結果が空でなければギフトコードを表示します
- 復号に失敗した場合は「合言葉が違います」と表示します

## セキュリティ上の注意

- **暗号化文字列の生成スクリプト (`scripts/encrypt-gift-code.js`) は、実行後に削除するか、ギフトコードと合言葉を削除してください**
- 暗号化は完全な保護を提供するものではありません。決意のあるユーザーはブラウザの開発者ツールを使って復号処理を解析できます
- この機能は「ちょっとした隠蔽」として機能し、ソースコードを直接読んだだけではギフトコードが分からないようにするものです
- より高いセキュリティが必要な場合は、サーバーサイドでの検証を実装してください

## トラブルシューティング

### 「合言葉が違います」と表示される
- 合言葉が正確に一致しているか確認してください（大文字小文字、スペースなども含めて完全一致が必要です）
- 暗号化時と復号時で同じ合言葉を使用しているか確認してください

### ギフトコードが表示されない
- ブラウザのコンソールにエラーが表示されていないか確認してください
- `ENCRYPTED_GIFT_CODE` が正しく設定されているか確認してください
- ゲームが正常にクリア状態（`gameStatus === 'cleared'`）になっているか確認してください
